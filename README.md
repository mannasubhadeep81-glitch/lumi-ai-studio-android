# LUMI AI Studio Android

Android WebView wrapper for the LUMI AI Studio preview.

## Build APK

1. Push to `main` or run the **Build Android APK** workflow from the Actions tab.
2. Open the successful workflow run.
3. Download the `lumi-ai-studio-debug-apk` artifact and extract the APK.

This is a wrapper around the hosted LUMI preview; it does not add AI video-generation backend functionality. Internet access is required.
